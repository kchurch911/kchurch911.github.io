# 123 Prayer (사역자 기도 언약) — 설치 안내

## 구성
| 파일 | 용도 | 주소 (배포 후) |
|---|---|---|
| `index.html` | 사역자용 기도 제목 제출 폼 (한/영) | https://kchurch911.com/123prayer/ |
| `pray.html` | 김성수 기도방 — 목록 보기, "기도함" 기록, 상태 변경 (비밀번호) | https://kchurch911.com/123prayer/pray.html |
| `Apps_Script_123Prayer.gs` | Google Sheet 저장 백엔드 (Apps Script 웹 앱) | — |

## 1. Apps Script 배포 (한 번만, 5분)
1. sheets.google.com → 새 스프레드시트 → 이름 **123 사역자 기도**
2. 메뉴 **확장 프로그램 → Apps Script** → 코드 칸 비우고 `Apps_Script_123Prayer.gs` 전체 붙여넣기
3. 코드 위쪽 `PRAY_KEY = 'CHANGE_ME'` 를 **원하는 비밀번호**로 바꾸기 (기도방 입장 비밀번호 — 이 저장소 파일에는 실제 비밀번호를 넣지 않습니다)
   - 새 기도 제목이 올 때 이메일 알림을 받으려면 `NOTIFY_EMAIL = ''` 에 이메일 입력
4. Ctrl+S → **배포 → 새 배포** → 톱니바퀴 → **웹 앱** → 실행: **나** / 액세스: **모든 사용자** → **배포** → 권한 허용(고급 → 이동 → 허용)
5. **웹 앱 URL**(…/exec) 복사

## 사용
- 사역자: 이름·섬기는 자리·기도 제목 1~2개·긴급 여부·공개 범위·123 언약 체크 → 보내기
- 김성수: `pray.html` → 비밀번호 → "기도 필요" 탭에 이번 주 2회가 안 된 사역자가 먼저 보임 → **기도함 — 3초 이상** 버튼 (하루 1회, 주 2회 채우면 "이번 주 완료") → 상태(기도중/응답됨/부분응답/종료) 변경 가능 → 인쇄 버튼으로 기도 목록 출력
- 기도 기록·상태는 Google Sheet에 저장되어 휴대폰·노트북 어디서든 같은 화면

## v5 (2026-08-22) — 명단·개인 페이지·갱신·응답
- 시트 2장: **123 사역자 기도**(기도 제목, 제출마다 1행) + **사역자 명단**(사람마다 1행: 토큰·첫 등록일·최근/다음 갱신일·상태·받은 기도·응답 건수·메모·최근 제목)
- **my.html?t=토큰** — 개인 기도 페이지: 내 제목·상태, 김목사 기도제목, "응답 받았어요"(+감사 한 줄), 새 기도 제목 보내기, "올해도 계속 기도해 주세요"(갱신), 연락처 수정. 링크는 제출 직후 화면과 확인 메일에 담김
- 기도방(pray.html) 탭: **기도 / 명단 / 김목사 기도제목**. 명단: 검색·상태 필터(활동/갱신 대기/보관)·메모·개인 링크 복사·연락처 복사. 김목사 기도제목은 여기서 수정 → 폼·메일·개인 페이지 자동 반영
- 연 1회 갱신: 기도방을 열 때마다 스크립트가 점검(?cron=1) → 갱신일 D-14 "곧 갱신", D-day "갱신", D+14 "마지막 안내 후 보관" 메일(이메일 있는 분만). 갱신/새 제목 보내기 시 1년 연장
- 응답: 본인이 표시하거나 김목사가 상태를 "응답됨"으로 바꾸면 서로 보이고, 이메일이 있으면 "응답을 함께 기뻐합니다" 메일
- 폼: 소속 교회·기관(선택), 기도 대상(나 / 소중한 분 + 이름), 접수 확인 메일(이메일일 때만)
- 날짜는 시트에 텍스트로 저장(자동 날짜 변환 방지). 디버그: `?tz=1`
